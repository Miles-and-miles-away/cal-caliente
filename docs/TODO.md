## ⚠️ Listed as complete but worth knowing

- **Facebook / Instagram / RSS scraper adapters.** These exist as classes but their `scrape()` methods return `[]` after fetching. They are not implementations. Don't expect data from them until tokens (FB/IG) or a parser (RSS) are wired up. The HTML adapter is the only one producing real events.
- **Documentation files (8/8).** All present, but `docs/api.md` had drift that was patched in the security pass — still worth re-reading after the v1 validation lands, since the new sources / canonical key won't be reflected there.

## 🚫 Explicitly not doing (with reasons)

- **Facebook / Instagram public-page scraping.** Meta's public APIs don't expose the data anyone would need (events from accounts the user follows). HTML scraping is JS-rendered and ToS-violating. The screenshot-share flow above is the realistic substitute.
- **latindancecalendar.com beyond static HTML.** Their main listing is JS-rendered. The static portion (`Featured deals` / `Festivals near here`) gives 2-3 useful festivals; that's already wired up. Going further requires Playwright/Chromium — not justified for that incremental data.
- **goandance.com.** Verified Europe-only; zero Japan events.
